Cost by model and effort

Each model with the effort levels it ran at, recorded per call: one row when a model ran at a single effort, otherwise the model's total with each effort nested under it. In is everything sent to the model (fresh input, cache writes, cache reads) and Out is what it wrote; $ In and $ Out are what each side cost, and the $ / 1M columns are the price actually paid per million tokens. Effort is only meaningful for the model it ran on, so it is never summed across models.

Model x effort

The same figures as a grid: estimated cost for each model at each effort level, with tokens in and out and $ in and out under it. Darker cells cost more.

Cost per task by model and effort

A task is one prompt and everything Claude did for it, grouped by the model and effort that cost the most in it. Few tasks means a noisy average.

Where the cost goes

Every call re-sends the whole conversation. Cache reads are that carried context at a tenth of the input rate; output is what Claude writes.

Context carried per call

Tokens sent to the model on each call of the main conversation (fresh input, cache writes, and cache reads). It grows as the conversation does; a sharp drop is a /clear or a compaction. Subagents carry their own context and are not drawn.
